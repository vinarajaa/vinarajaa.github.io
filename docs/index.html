02 / THE LORE

How the site evolved

  1. May 2025

    The animated portfolio takes shape

    The homepage grows through many small visual, motion, résumé, project-image, contact, and responsive-layout commits. The current page still carries that experimental Webflow-and-GSAP DNA.

  2. May 12, 2025

    The database idea appears

    The first home-database project is introduced locally and linked into the portfolio.

  3. February 6, 2026

    The site becomes a project neighborhood

    Database, NYC Events, Apps, Junkyard, Tech Stack, Timeline, and Crash Monitoring routes are established together. NYC Events then goes through an especially energetic run of filtering, scraper, date, area, and UI refinements.

  4. March 2026

    The résumé becomes interactive

    The Timeline page receives multiple rounds of interaction and aesthetic work, followed by homepage menu changes.

  5. August 30, 2026

    The big usability refresh

    The homepage and interactive project pages are reorganized into cleaner, more usable interfaces while preserving their individual personalities.

  6. August 31, 2026

    One visual family—and documentation

    Database and NYC Events adopt the portfolio palette, homepage spacing and navigation are corrected, Playground is tucked away, broken legacy runtime code is removed, and this living guide arrives.

03 / SHARED INGREDIENTS

The rules holding it together

COLOR

Cream + chocolate + chaos

#ffe9cf and #270f03 form the base. Bright green, pink, blue, yellow, orange, and purple make each tool feel playful without losing the family resemblance.

TYPE

Big voice, useful details

Anton or expressive display faces do the shouting. Work Sans, IBM Plex Mono, and other compact utility faces keep interfaces readable.

MOTION

Motion with a job

The homepage uses GSAP and Lenis for expressive storytelling. Tool pages stay lighter, using small transitions and respecting reduced-motion preferences.

DATA

Useful without a backend

Interactive projects prefer real APIs when available, then provide local demo data or browser storage so the experience remains understandable and testable.

DEPLOYMENT

Two GitHub homes

The portfolio deploys through vinarajaa/vinarajaa.github.io. Embagent remains separate under embadmin/embagentlanding.

MAINTENANCE

Keep the whimsy, remove the friction

Cleanup should preserve icons, color, animation, and voice while removing broken bundles, inaccessible controls, stale links, accidental duplication, and layout hacks.

04 / THE ATTIC

Hidden and legacy pages

Apps Playground is still available in the source at /apps/, but it is intentionally hidden from the homepage while it waits for its next direction.

Older template pages—including about.html, contact.html, work.html, index2.html, and several files under /pages/—are historical artifacts. They are not treated as the current public navigation and remain useful as references for earlier experiments.

Scraper debug pages under /scrapers/ support development and troubleshooting; they are tools, not visitor destinations.
